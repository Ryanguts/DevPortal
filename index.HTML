Por onde começar

Como usar este portal

1. Oriente-se

Se você não sabe por onde começar, abra o quiz na home ou a página de Trilhas. Elas não substituem a prática, mas evitam que você estude cinco coisas ao mesmo tempo sem direção.

2. Compare com critério

O comparador mostra diferenças reais entre linguagens — quando cada uma brilha. Use isso para escolher a próxima habilidade, não para entrar em guerra de fanbases.

3. Pratique lógica

Antes de memorizar sintaxe, domine sequência, decisão e repetição. A seção de lógica reúne conceitos, mini-desafios e cursos gratuitos e pagos.

4. Pesquise formação

A busca de faculdades usa uma base mundial (dataset Hipo). Confirme sempre no site oficial da instituição grades, modalidades e processos seletivos.

O DevPortal é orientativo: o mercado muda, as vagas variam por região e a melhor stack depende do problema. Seu diferencial continua sendo projetos concluídos, clareza ao explicar decisões e constância de estudo.

Conta local e privacidade

O botão Entrar cria uma conta neste navegador com e-mail e senha. Os dados ficam no localStorage (favoritos podem ser vinculados à conta). Não enviamos credenciais a um servidor: é um protótipo didático de autenticação. Em um produto real, isso seria uma API com banco de dados, hash forte (bcrypt/argon2) e HTTPS.

Limpar dados do site no navegador apaga a conta local. Use apenas senhas de teste aqui.

Categorias

💡 HTML, CSS e SQL são programação?

No sentido estrito, não. HTML é marcação, CSS é estilo e SQL é consulta a dados. Nenhuma substitui uma linguagem com lógica completa — mas as três são fundamentais em TI, por isso estão neste catálogo.

🔌 O que é uma API?

API é um contrato entre sistemas. Na web, costuma ser um endpoint HTTP que devolve JSON. JS/TS, Python, Go, Java e C# são comuns para criar APIs; no front você as consome.

🔌 O que é uma API?

API: contrato entre sistemas, em geral HTTP + JSON. Usada o tempo todo em apps e sites.

🧠 Lógica de Programação

A base que sustenta qualquer linguagem. Revise os conceitos essenciais e encontre cursos — muitos gratuitos — para praticar.

Lógica de programação é o conjunto de técnicas para organizar o raciocínio e resolver problemas de forma clara e estruturada — independentemente da linguagem que você use depois. Quem domina lógica aprende qualquer linguagem com mais velocidade: Python, JavaScript, Java ou C# são, em essência, sintaxes diferentes para as mesmas ideias — sequência, decisão e repetição.
